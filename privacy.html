The Lab Tenant Manager Application

Lab Tenant Manager is a self-hosted application. When you deploy it using the instructions on this website, it runs entirely within your own Azure subscription. All data (tenant records, lab-user accounts, audit logs, tokens) is stored in an Azure Cosmos DB instance you control.

The operator of this promotional website (Holger Imbery) has no access to any data processed by deployed instances of Lab Tenant Manager. Each deployment is independent and under the full control of the party who performed the deployment.

  • Holger Imbery does not receive telemetry, usage statistics, or diagnostics from deployed instances.
  • The pre-built container image is pulled from GitHub Container Registry (ghcr.io) at deploy time only.
  • No callbacks, webhooks, or license-check requests are made to any server operated by Holger Imbery.
